# 两个方向的论文阅读库

整理与查新截止日期：2026-10-27。

## 为什么这样选

1. **基础与代表性：** Transformer、FlashAttention、PagedAttention、推测解码、量化；Agent的交互、修复、验证、记忆与训练。
2. **与你的积累衔接：** STARS，以及组内LAVa、SmallKV、TrigReason、Retrospex、LifeBench等。它们帮助你尽快和导师同学讨论具体问题。
3. **对照与反证：** 不只读报告提升的论文，也读自纠错局限、评估器偏差和训练失败诊断，理解结论适用条件。
4. **近期查新：** 2026正式会议工作与2026年8–10月相关预印本分开标注。最新条目包含10月的循环推理分析与10月23日的ImageRSI。

本库不穷尽所有分支。暂未展开MoE通信、扩散语言模型、多模态推理系统和大规模多Agent协作，以免当前阅读面过宽。基础清楚、兴趣明确后再补。

## “重要”“高质量”“最新”分别怎么判断

- **重要：** 能帮助你理解后续工作所依赖的机制、建立强基线或认识关键反例，不只依据引用量。
- **高质量候选：** 优先有正式同行评审记录、问题和方法清晰、实验可分析的代表工作。正式发表也不自动保证结论普遍有效。
- **最新：** 与候选课题直接相关的近期变化，主要用于避免重复研究；新颖程度与可信程度分开判断。

A/B/C代表阅读用途。C中也可能有正式顶会论文，如OSDI 2026的Strata；也包含尚未核实正式发表的预印本。不能将C整体等同于“已证明的最新最佳方法”。

发表状态区分：正式论文集核对、作者/项目页标注、arXiv作者备注、未独立确认。未确认不等于未发表。arXiv首发年份、会议年份和最新修订年份分别看，避免误把2025首发、2026录用的论文算成不同工作。

## 推荐前六周安排

假设每周读2–3篇并做少量实验，主方向约占三分之二时间。读不完就延长周期，不要牺牲理解。

| 周次 | 效率方向 | Agent方向 | 应留下的产出 |
| --- | --- | --- | --- |
| 第1周 | E01地图；E02复习 | A01 ReAct | 两个方向的概念图、一个最小运行流程 |
| 第2周 | E03 FlashAttention | A02 Self-Refine | IO与计算的区别；任务内修复流程 |
| 第3周 | E04 PagedAttention | A03 Reflexion | 缓存与并发解释；任务内修复/跨尝试记忆对比 |
| 第4周 | E05推测解码 | A04局限与A27 CRITIC对照 | 有外部反馈与无外部反馈的假设表 |
| 第5周 | E06 AWQ | A05 tau2 | 质量—资源评价表；可执行成功检查器 |
| 第6周 | E07 STARS、E08计算预算 | A06 Retrospex、A08 LongMemEval先读设置 | 一页候选问题；明确后续选择哪个分支 |

最后一周内容较多：STARS可利用已有积累复习，Agent两篇可先看任务和核心机制。若概念尚不熟，拆成两周。DPO/PPO和多轮RL放到你真正进入训练分支时再精读。

## 每篇读到什么程度

第一遍约30–60分钟：问题、机制图、实验设置和主要限制。第二遍选核心论文精读：方法细节、强基线、消融、预算和附录。时间只是参考，数学或系统背景不足时要补基础。

读完能讲清：它针对什么失败、改变了什么、和基线是否公平、增加多少成本、结论不能推广到哪里。使用[阅读笔记模板](阅读笔记模板.md)，每篇先写一页，不要求逐段翻译。
